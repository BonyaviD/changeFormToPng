# سامانه صدور گواهی

برنامه‌ی صدور، بایگانی و استعلام گواهی‌های پایان دوره‌ی آموزشی مرکز تحقیقات حلال.
بازنویسی‌شده با Next.js، TypeScript، Tailwind v4 و shadcn/ui.

```bash
npm install
npm run dev      # http://localhost:3000
npm run auth:setup # ساخت هش رمز و کلید نشست در .env.local
npm run build
npm start
npm test         # آزمون‌های ورود و نشست
```

## چه می‌کند

| صفحه | کار |
| --- | --- |
| `/` | پر کردن فرم، پیش‌نمایش زنده، دانلود PNG یا PDF |
| `/bulk` | بارگذاری اکسل/CSV و دریافت همه‌ی گواهی‌ها در یک ZIP |
| `/history` | آرشیو گواهی‌های صادرشده و صدور دوباره‌ی هرکدام |
| `/verify` | استعلام گواهی با شماره پیگیری |
| `/settings` | فهرست دوره‌ها، امضاکنندگان و عناوین سربرگ |

کنترل ورود روی سرور Next.js / Vercel انجام می‌شود. خروجی استاتیک و GitHub Pages
برای این نسخه پشتیبانی نمی‌شوند؛ میزبانی باید runtime خود Next.js را اجرا کند.
صدور گواهی و آرشیو همچنان در مرورگر انجام می‌شوند. آرشیو در `localStorage` همان مرورگر نگهداری می‌شود، و هر گواهی یک شماره
پیگیری می‌گیرد که روی خود سند چاپ نمی‌شود و فقط برای بازیابی از آرشیو است.

## ورود و انتشار

سه متغیر **فقط سمت سرور** در `.env.example` تعریف شده‌اند:
`SARA_AUTH_USERNAME`، `SARA_AUTH_PASSWORD_HASH` و `SARA_SESSION_SECRET`.
`npm run auth:setup` آن‌ها را با scrypt و کلید تصادفی در فایل نادیده‌گرفته‌شدهٔ
`.env.local` می‌سازد؛ رمز خام ذخیره نمی‌شود. همین سه مقدار را در Environment
Variables پروژهٔ Vercel با نوع **Secret** ثبت کنید و دوباره دیپلوی کنید. برای
Production از Secret تولیدی اصلی استفاده کنید؛ در صورت نیاز به Preview، آن را
برای شاخهٔ مشخص Preview نیز جداگانه تعریف کنید. در کپی دستی از `.env.local`،
بک‌اسلش قبل از `$` صرفاً escape مربوط به dotenv است و جزئی از مقدار متغیر نیست.
هیچ‌کدام نباید `NEXT_PUBLIC_` باشند. نبود تنظیمات باعث بسته‌ماندن دسترسی می‌شود.

ورود با فرم سرور انجام می‌شود؛ فقط `/login` و درخواست ورود عمومی هستند. تمام
صفحات، RSC، APIها، فونت‌ها و فایل‌های عمومی از Proxy عبور می‌کنند و لایهٔ layout
نیز نشست را مستقل بررسی می‌کند. صفحهٔ ورود اسکریپت و فایل خارجی ندارد.
کوکی امضاشده در Production دارای `Secure`، `HttpOnly`، `SameSite=Strict` و
پیشوند `__Host-` است. پس از ۱۰ روز عدم استفاده منقضی می‌شود؛ مراجعه و فعالیت
واقعی مهلت را تمدید می‌کنند، ولی polling خودکار این کار را نمی‌کند. خروج دستی
کوکی را پاک می‌کند و تب‌های باز را به ورود برمی‌گرداند. تغییر رمز/نام کاربری/کلید
در تنظیمات Vercel و دیپلوی مجدد، همهٔ نشست‌های قبلی را نامعتبر می‌کند. درون سایت
امکان تغییر رمز یا ایجاد کاربر وجود ندارد.

کنترل تعداد تلاش ورود در هر نمونهٔ سرور اعمال می‌شود؛ محدودیت سراسری میان
نمونه‌ها و مناطق مختلف باید با Vercel Firewall یا یک مخزن مشترک اعمال شود.
نشست‌ها بدون دیتابیس‌اند؛ حذف کوکی در خروج، نسخهٔ از قبل سرقت‌شدهٔ همان کوکی را
روی سرور ابطال نمی‌کند. برای ابطال همهٔ نشست‌ها، کلید نشست را عوض کنید.

این ورود از دسترسی بازدیدکنندهٔ واردنشده به نسخهٔ جاری سایت جلوگیری می‌کند؛
امضای قابل‌مشاهده برای کاربر واردشده، دادهٔ ذخیره‌شده در همان پروفایل مرورگر و
فایل‌های موجود در تاریخچهٔ عمومی گیت یا دیپلوی‌های قدیمی با آن محافظت نمی‌شوند.
هیچ تصویر امضایی را در public یا کد منتشر نکنید. کنترل Inspect یا غیرفعال‌کردن
راست‌کلیک مرز امنیتی نیست.

## ساختار

```
src/
  app/                     مسیرها (هرکدام یک لایه‌ی نازک روی یک workspace)
  components/
    ui/                    پایه‌های shadcn
    layout/                پوسته‌ی برنامه و سربرگ صفحات
    form/                  کنترل‌های فرم + تقویم شمسی
    certificate/           بوم پیش‌نمایش و میز کار صدور
    bulk/ archive/ verify/
  lib/
    templates/             ← قالب‌های گواهی
    render/                گرفتن تصویر، ساخت PDF، دانلود
    storage/               آرشیو (قابل تعویض با API)
    settings/              کاتالوگ دوره‌ها، امضاکنندگان و عناوین سربرگ
    bulk/                  خواندن و نگاشت فایل ورودی
    jalali.ts persian.ts serial.ts fonts.ts
```

## کاتالوگ‌ها

عنوان دوره، امضاکننده و عنوان زیر لوگوی سربرگ از فهرست‌هایی می‌آیند که در
`/settings` نگهداری می‌شوند (پیش‌فرض‌ها در `src/lib/settings/`). فیلد فرم با
`optionsSource` به یکی از این فهرست‌ها وصل می‌شود و با `optionsFillMap` می‌گوید
انتخابِ یک مورد کدام فیلد دیگر را پر کند — به همین شکل انتخاب دوره کد گواهی را
هم می‌آورد. هر فیلد کاتالوگی متن آزاد را هم می‌پذیرد، چون دوره‌ی تازه باید همان
روز قابل صدور باشد.

آنچه روی گواهی چاپ می‌شود در خودِ رکورد آرشیو ذخیره می‌شود، نه ارجاع به کاتالوگ؛
پس ویرایش بعدی فهرست‌ها گواهی‌های صادرشده را تغییر نمی‌دهد. استثناء تصویر امضاست
که به‌خاطر حجم، هنگام رندر از کاتالوگ خوانده می‌شود.

## فونت‌ها

دو قلم روی سند کار می‌کنند: نستعلیق برای «بسم تعالی» و عنوان، و یک نسخ کلاسیک
(Amiri) برای هر چیزی که باید خوانده شود — نام، کد ملی، متن بدنه و سربرگ. رابط
کاربری با Vazirmatn است. هر سه self-host شده‌اند.

تصاویر امضا همیشه به محدوده‌ی جوهرشان برش می‌خورند (چه تصویر همراه برنامه، چه
آپلود جدید)، چون طرح، امضا را با کادرش جای می‌دهد و اسکنِ برش‌نخورده به‌جای خطوط،
حاشیه‌ی خالی را می‌نشاند.

## افزودن قالب جدید

یک پوشه در `src/lib/templates/<id>/` بسازید که یک `CertificateTemplate`
(تعریف‌شده در `src/lib/templates/types.ts`) صادر کند و آن را به آرایه‌ی
`templates` در `registry.ts` اضافه کنید. قالب شامل این‌هاست:

- `schema` — اعتبارسنجی Zod
- `groups` — تعریف فیلدها؛ فرم، ویرایشگر گروهی و نگاشت ستون‌های اکسل خودکار از
  روی همین ساخته می‌شود
- `size` و `Artwork` — بوم با ابعاد ثابت و کامپوننت طرح

هیچ صفحه‌ای لازم نیست تغییر کند.

## چرا خروجی روی همه‌ی دستگاه‌ها یکسان است

- `pixelRatio` روی ۲ قفل شده؛ خروجی همیشه ۲۳۰۰×۱۶۴۰ پیکسل است، مستقل از
  رزولوشن نمایشگر.
- فونت‌ها به‌صورت base64 داخل خود اسنپ‌شات جاسازی می‌شوند؛ اگر فونت روی سیستم
  نصب نباشد هم چیزی عوض نمی‌شود.
- طرح گواهی روی بوم ثابت ۱۱۵۰×۸۲۰ با مختصات مطلق چیده شده، نه با چیدمان جریانی.
- عکس‌برداری از یک نسخه‌ی جداگانه و بدون scale انجام می‌شود، نه از پیش‌نمایشِ
  کوچک‌شده.

## پوسته‌ها

| پوسته | کاربرد |
| --- | --- |
| روشن | رابط رسمی با زمینهٔ کاغذی و آبی سازمانی |
| تیره | نسخهٔ کم‌نور همان سیستم طراحی |
| فرمول یک | رابط مسابقه‌ای مشکی و قرمز با بافت فیبرکربن و نشان Race Mode |

است و هیچ‌کدام رنگ، ابعاد یا محتوای خروجی PNG/PDF گواهی را تغییر نمی‌دهند.
